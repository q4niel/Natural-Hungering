# Natural Hungering
- All exhaustion *(hunger)* values have been divided by 100
- The player now accumulates exhaustion *(hunger)* continually, even when stationary

## Optional TOML Customization
### File path: config/natural_hungering.toml
```toml
# This (#) is a comment

# Divides all exhaustion (must be decimal)
exhaustion_divider = 100.0

# Exhaustion gained over time (must be decimal)
passive_exhaustion = 0.001
```
